# Excel Sales Dashboard Project 📊

## 📌 Project Overview
This project analyzes sales data using Microsoft Excel to generate business insights through an interactive dashboard.

## 🔗 Project Resources
- **Dataset:** [View Dataset](https://github.com/rajneeshyadav740/Excel-Sales-Dashboard/blob/main/Excel%20Sales%20Dashboard.xlsx)
- **Dashboard Demo Video:** [Watch Dashboard Video](https://github.com/rajneeshyadav740/Excel-Sales-Dashboard/blob/main/Dashboard%20Video.mp4)

## 🛠️ Tools & Technologies
- Microsoft Excel
- PivotTables & PivotCharts
- Excel Formulas
- Slicers
- Data Cleaning & Visualization

## 📈 Key KPIs
- Total Revenue
- Total Gross Profit
- Gross Profit Margin
- Total Units Sold
- Total Orders
- COGS

## 🔍 Key Analysis
- Top 5 Countries by Sales
- Revenue by Region and Sales Channel
- Revenue and Profit Analysis
- Interactive Dashboard with Slicers

## 💡 Key Learnings
Data cleaning, KPI calculation, PivotTables, data analysis, and dashboard creation.
